# Managed Apps presentation assets

`icon.svg` is an original Spitzli Cloud pictogram, created for this repository.
Purple `#6515D5` and white match the Spitzli Cloud identity; UI text uses the
platform charcoal. It depicts the capability and does not reproduce a provider
trademark or imply provider endorsement. The repository license applies.

Screenshots, where present, show actual product components or integration views.
Their README captions state whether data and operations are synthetic. They are
not evidence of a deployed provider, customer activation or delivery.

Presentation changes require a new immutable release version. Keep existing
signed manifests, release assets and image references unchanged. Resolve relative
asset paths against the new source tag or immutable commit, never `main`.
